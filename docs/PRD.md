# 견적서 웹 뷰어 & PDF 다운로드 MVP PRD

## 🎯 핵심 정보

**목적**: Notion에 입력한 견적서를 클라이언트가 별도 프로그램 없이 웹에서 확인하고 PDF로 저장할 수 있게 한다
**사용자**: Notion으로 견적서를 관리하는 프리랜서·소규모 사업자(관리자)와, 공유 링크로 견적서를 전달받는 클라이언트

## 🚶 사용자 여정

```
1. 로그인 페이지
   ↓ 이메일/비밀번호 로그인

   [계정 없음] → 회원가입 페이지 → 로그인 페이지로 복귀
   ↓

2. 대시보드 (Notion 견적서 목록 표시)
   ↓ 견적서 선택

   [미리보기] → 견적서 열람 페이지 (관리자가 직접 확인)
   [공유 링크 복사] → 클라이언트에게 링크 전달
   ↓

3. 견적서 열람 페이지 (클라이언트, 비로그인 접근)
   ↓ 내용 확인 후 PDF 다운로드 버튼 클릭

4. PDF 파일 다운로드 완료
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F001]** | Notion 견적서 동기화 조회 | 연결된 Notion 데이터베이스에서 견적서 목록(고객명, 금액, 작성일 등)을 가져와 표시 | 견적서를 이중 입력하지 않고 Notion 데이터를 그대로 활용 | 대시보드 |
| **[F002]** | 견적서 상세 열람 | 클라이언트가 공유 링크로 접속해 품목, 단가, 수량, 합계, 유효기간을 웹에서 확인 | 클라이언트가 로그인 없이 견적서 내용을 확인할 수 있어야 함 | 견적서 열람 페이지 |
| **[F003]** | PDF 다운로드 | 견적서 열람 페이지에서 현재 견적서를 PDF 파일로 저장 | 클라이언트의 오프라인 보관·증빙 제출 요구 충족 | 견적서 열람 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F010]** | 기본 인증 | 회원가입/로그인/로그아웃만 | 관리자가 대시보드를 이용하기 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **[F011]** | 공유 링크 생성 | 견적서별로 추측하기 어려운 고유 링크를 생성하고 복사 | 클라이언트에게 전달할 접근 경로가 있어야 함 | 대시보드 |

### 3. MVP 이후 기능 (제외)

- 링크 만료 기간 설정 및 조회 로그
- 이메일 자동 발송
- 전자서명
- 다국어 지원
- 결제 연동
- PDF 워터마크·회사 로고 커스터마이징

## 📄 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **메뉴 위치:** 비로그인 시 기본 진입 페이지

| 항목 | 내용 |
|------|------|
| **역할** | 관리자 인증 전용 페이지 |
| **진입 경로** | 비로그인 상태에서 서비스 접속 시 자동 진입, 또는 회원가입 완료 후 이동 |
| **사용자 행동** | 이메일/비밀번호 입력 후 로그인 |
| **주요 기능** | • 이메일/비밀번호 로그인 폼<br>• 회원가입 페이지 이동 링크<br>• **로그인** 버튼 |
| **다음 이동** | 성공 → 대시보드, 실패 → 에러 메시지 표시 |

---

### 회원가입 페이지

> **구현 기능:** `F010` | **인증:** 불필요

| 항목 | 내용 |
|------|------|
| **역할** | 관리자 계정 생성 전용 페이지 |
| **진입 경로** | 로그인 페이지에서 "회원가입" 링크 클릭 |
| **사용자 행동** | 이메일/비밀번호/이름 입력 후 계정 생성 |
| **주요 기능** | • 회원가입 폼(이메일, 비밀번호, 이름)<br>• 로그인 페이지 이동 링크<br>• **가입하기** 버튼 |
| **다음 이동** | 성공 → 로그인 페이지 |

---

### 대시보드

> **구현 기능:** `F001`, `F011` | **인증:** 로그인 필요

| 항목 | 내용 |
|------|------|
| **역할** | Notion 연동 견적서 목록을 확인하고 클라이언트에게 전달할 공유 링크를 관리하는 관리자 홈 |
| **진입 경로** | 로그인 성공 후 자동 이동 |
| **사용자 행동** | 견적서 목록 조회, 특정 견적서의 공유 링크 생성/복사, 견적서 미리보기 |
| **주요 기능** | • Notion 데이터베이스 견적서 목록 표시(고객명, 금액, 작성일)<br>• 견적서별 **공유 링크 복사** 버튼<br>• 견적서 카드 클릭 시 견적서 열람 페이지로 미리보기 이동 |
| **다음 이동** | 견적서 선택 → 견적서 열람 페이지, 로그아웃 → 로그인 페이지 |

---

### 견적서 열람 페이지

> **구현 기능:** `F002`, `F003` | **인증:** 불필요 (공유 링크 기반 공개 접근)

| 항목 | 내용 |
|------|------|
| **역할** | 클라이언트가 견적서 내용을 확인하고 PDF로 저장하는 공개 열람 페이지 |
| **진입 경로** | 공유 링크로 직접 접속, 또는 대시보드에서 관리자가 미리보기로 접속 |
| **사용자 행동** | 품목, 단가, 수량, 합계, 유효기간 확인 후 PDF 다운로드 |
| **주요 기능** | • 견적서 상세 내용 표시(품목, 단가, 수량, 합계, 유효기간)<br>• **PDF 다운로드** 버튼<br>• 유효하지 않은 링크 접근 시 에러 표시 |
| **다음 이동** | PDF 다운로드 → 파일 저장 완료(페이지 유지) |

## 🗄️ 데이터 모델

### User (관리자 계정)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |

| password | 비밀번호(해시 저장) | string |

| created_at | 계정 생성일시 | timestamp |

|------|------|----------|
| id | 고유 식별자 | UUID |

| token | 공유용 고유 토큰(URL에 사용) | string |
